
# MediSense Guardian Mode

환자가 공유한 MediSense 분석 결과를 보호자가 **빠르고 이해하기 쉽게** 확인할 수 있도록 만든 단일 페이지 웹 앱입니다.

## 주요 기능
- 공유 링크 / share 토큰 기반 결과 불러오기
- 긴급도(낮음·중간·높음) 시각적 표시
- 보호자 행동 가이드 및 체크리스트 제공
- 추천 진료과, 병원 지도 검색(카카오맵 / 네이버지도)
- 인쇄 및 요약 복사 기능

## 실행 방법
별도 서버 없이 정적 파일로 동작합니다.

```bash
# 저장소 클론 후
open index.html
```
또는 GitHub Pages에 그대로 배포할 수 있습니다.

## 주의사항
- 본 프로젝트는 **의료 진단을 대체하지 않습니다.**
- 응급 상황이 의심되면 즉시 119 또는 응급실을 이용하세요.
